specgen generates C++ standard library description wording from annotated headers.
These are the pages of its documentation that are meant to be read in a browser.
The source, and the rest of the documentation, is in the [[https://github.com/steve-downey/specgen][repository]].

* Examples

- [[file:examples.org][CLI examples]]: each command, and the output the test suite checks it against.
- [[file:examples-live.org][Live examples]]: the same kind of commands, run by the released specgen when this page was built.
