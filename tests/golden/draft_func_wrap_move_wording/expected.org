#+begin_pnum
The header provides partial specializations of ~move_only_function~ for each combination of the possible replacements of the placeholders @@latex:\cv{}@@@@html:<i>cv</i>@@, @@latex:\placeholder{ref}@@@@html:<i>ref</i>@@, and @@latex:\placeholder{noex}@@@@html:<i>noex</i>@@ where

- @@latex:\cv{}@@@@html:<i>cv</i>@@ is either const or empty,
- @@latex:\placeholder{ref}@@@@html:<i>ref</i>@@ is either ~&~, ~&&~, or empty, and
- @@latex:\placeholder{noex}@@@@html:<i>noex</i>@@ is either ~true~ or ~false~.
#+end_pnum

#+begin_pnum
For each of the possible combinations of the placeholders mentioned above, there is a placeholder @@latex:\placeholder{inv-quals}@@@@html:<i>inv-quals</i>@@ defined as follows:

- If @@latex:\placeholder{ref}@@@@html:<i>ref</i>@@ is empty, let @@latex:\placeholder{inv-quals}@@@@html:<i>inv-quals</i>@@ be @@latex:\cv{}@@@@html:<i>cv</i>@@~&~,
- otherwise, let @@latex:\placeholder{inv-quals}@@@@html:<i>inv-quals</i>@@ be @@latex:\cv{}@@@@html:<i>cv</i>@@ @@latex:\placeholder{ref}@@@@html:<i>ref</i>@@.
#+end_pnum

#+begin_pnum
The ~move_only_function~ class template provides polymorphic wrappers that generalize the notion of a callable object([[https://eel.is/c++draft/func.def][@@html:[func.def]@@@@latex:{[}func.def{]}@@]]). These wrappers can store, move, and call arbitrary callable objects, given a call signature.
#+end_pnum

#+begin_pnum
/Recommended practice/: Implementations should avoid the use of dynamically allocated memory for a small contained value.

#+begin_note
Such small-object optimization can only be applied to a type ~T~ for which ~is_nothrow_move_constructible_v<T>~ is ~true~.
#+end_note
#+end_pnum

#+begin_pnum
Let ~VT~ be ~decay_t<F>~.
#+end_pnum

#+begin_pnum
/Constraints/:

- ~remove_cvref_t<F>~ is not the same type as ~move_only_function~, and
- ~remove_cvref_t<F>~ is not a specialization of ~in_place_type_t~, and
- @@latex:\tcode{\exposid{is-callable-from}<VT>}@@@@html:<code><var>is-callable-from</var>&lt;VT&gt;</code>@@ is ~true~.
#+end_pnum

#+begin_pnum
/Mandates/: ~is_constructible_v<VT, F>~ is ~true~.
#+end_pnum

#+begin_pnum
/Preconditions/: ~VT~ meets the @@latex:\oldconcept{Destructible}@@@@html:<i>Cpp17Destructible</i>@@ requirements, and if ~is_move_constructible_v<VT>~ is ~true~, ~VT~ meets the @@latex:\oldconcept{MoveConstructible}@@@@html:<i>Cpp17MoveConstructible</i>@@ requirements.
#+end_pnum

#+begin_pnum
/Postconditions/: ~*this~ has no target object if any of the following hold:

- ~f~ is a null function pointer value,
- ~f~ is a null member pointer value, or
- ~remove_cvref_t<F>~ is a specialization of the ~move_only_function~ or ~copyable_function~ class template, and ~f~ has no target object.

Otherwise, ~*this~ has a target object of type ~VT~ direct-non-list-initialized with ~std::forward<F>(f)~.
#+end_pnum

#+begin_pnum
/Throws/: Any exception thrown by the initialization of the target object. May throw ~bad_alloc~ unless ~VT~ is a function pointer or a specialization of ~reference_wrapper~.
#+end_pnum
