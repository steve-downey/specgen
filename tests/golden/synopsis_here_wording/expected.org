** Class template plain [demo.plain]
:PROPERTIES:
:CUSTOM_ID: demo.plain
:UNNUMBERED: t
:WG21_WORDING: t
:END:

#+begin_pnum
Subclause ([[https://eel.is/c++draft/demo.plain][@@html:[demo.plain]@@@@latex:{[}demo.plain{]}@@]]) describes the class template ~plain~.
#+end_pnum

#+begin_pnum
It holds nothing.
#+end_pnum

#+begin_codeblock
namespace std {
  template<class E>
  class plain {};
}
#+end_codeblock

#+begin_pnum
A program that instantiates ~plain<E>~ is ill-formed unless ~is_object_like<E>~ is ~true~.
#+end_pnum

#+begin_pnum
/Remarks/: A ~plain~ is trivially copyable.
#+end_pnum
