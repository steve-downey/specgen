\rSec3[demo.holder]{Class template holder}

\begin{codeblock}
namespace std {
  template<class E>
  class @\libglobal{holder}@ {};
}
\end{codeblock}

\pnum
Subclause \iref{demo.holder} describes the class template \tcode{holder}.

\pnum
A program that instantiates the definition of \tcode{holder} for a non-object type or an array type is ill-formed.


\rSec3[demo.slot]{Class template slot}

\begin{codeblock}
namespace std {
  template<class E>
  class @\libglobal{slot}@ {};
}
\end{codeblock}

\pnum
A program that instantiates the definition of \tcode{slot} for a non-object type is ill-formed, and \tcode{is_array_like<E>} is \tcode{false}.


\rSec3[demo.plain]{Class template plain}

\begin{codeblock}
namespace std {
  template<class E>
  class @\libglobal{plain}@ {};
}
\end{codeblock}

\pnum
A program that instantiates \tcode{plain<E>} is ill-formed unless \tcode{is_object_like<E>} is \tcode{true}.

\pnum
Subclause \iref{demo.plain} describes the class template \tcode{plain}.
