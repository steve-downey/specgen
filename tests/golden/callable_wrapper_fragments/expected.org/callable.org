#+begin_pnum
The ~callable_wrapper~ class template provides polymorphic wrappers that generalize the notion of a callable object([[https://eel.is/c++draft/func.def][@@html:[func.def]@@@@latex:{[}func.def{]}@@]]). These wrappers can store, move, and call arbitrary callable objects, given a call signature.
#+end_pnum

#+begin_pnum
/Recommended practice/: Implementations should avoid the use of dynamically allocated memory for a small contained value.

#+begin_note
Such small-object optimization can only be applied to a type ~T~ for which ~is_nothrow_move_constructible_v<T>~ is ~true~.
#+end_note
#+end_pnum

*** Construction [callable.ctor]

#+begin_pnum
/Postconditions/: ~*this~ has no target object if any of the following hold:

- ~f~ is a null function pointer value, or
- ~f~ is a null member pointer value, or
- ~f~ is an empty callable wrapper.

Otherwise, ~*this~ has a target object initialized with ~f~.
#+end_pnum

#+begin_itemdecl
template<class VT> static constexpr bool @\exposidnc{is-callable-from}@ = @\seebelow@;
#+end_itemdecl

#+begin_pnum
If the invocation is nonthrowing, @@latex:\tcode{\exposid{is-callable-from}<VT>}@@@@html:<code><var>is-callable-from</var>&lt;VT&gt;</code>@@ is equal to:

#+begin_codeblock
is_nothrow_invocable_r_v<R, VT, ArgTypes...>
#+end_codeblock

Otherwise, @@latex:\tcode{\exposid{is-callable-from}<VT>}@@@@html:<code><var>is-callable-from</var>&lt;VT&gt;</code>@@ is equal to:

#+begin_codeblock
is_invocable_r_v<R, VT, ArgTypes...>
#+end_codeblock

#+begin_wgexample
A callable target can be checked as follows:

#+begin_codeblock
static_assert(is_invocable_r_v<int, int (*)()>);
#+end_codeblock
#+end_wgexample
#+end_pnum
