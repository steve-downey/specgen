#+end_itemdecl

#+begin_itemdecl

#+begin_itemdecl

#+end_itemdecl

#+begin_itemdecl

#+end_itemdecl

/Remarks/: ~flag_v<T>~ is ~false~ unless a program specializes it.

#+begin_itemdecl

#+end_itemdecl

/Remarks/: The registration limit.

#+begin_itemdecl

#+end_itemdecl

/Remarks/: A type is usable if it names a member type.

#+begin_itemdecl
enum class color { red, green };
#+end_itemdecl

/Remarks/: The enumerators have the following meanings:

- ~red~ -- the default channel.
- ~green~ -- the channel a program selects.

#+begin_itemdecl

#+end_itemdecl

/Remarks/: The width of a link, in bytes.
