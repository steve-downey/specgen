#+begin_pnum
A reference qualifier is one of the following:

- ~&~, or
- ~&&~.

Special characters in code are literal: @@latex:\tcode{\# \% \_ \{ \} \textasciitilde{} \textasciicircum{} \$ \textbackslash{}}@@@@html:<code># % _ { } ~ ^ $ \</code>@@.
#+end_pnum
