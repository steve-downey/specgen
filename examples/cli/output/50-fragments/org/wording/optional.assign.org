** Assignment [optional.assign]

#+begin_itemdecl
template<class... Args> constexpr T& emplace(Args&&... args);
#+end_itemdecl

/Mandates/: ~is_constructible_v<T, Args...>~ is ~true~.

/Effects/: Destroys any contained value, then direct-non-list-initializes the contained value with ~std::forward<Args>(args)...~.

/Postconditions/: ~has_value()~ is ~true~.

/Returns/: A reference to the new contained value.
